# Gem Agency

## Platform
Web application, used locally by the agency owner on desktop with mobile access to the interface.

## Purpose
The owner describes a website idea, reviews deliverables, launches the website, and improves its traffic and conversions. Multiple client projects share one operating dashboard.

## Confirmed direction
The user selected the Growth Command Center concept in docs/dashboard-concepts/02-growth-command-center.png and requested implementation plus the Gem Agency gemstone-G identity.

## Stack and constraints
Existing vanilla JavaScript modules and CSS, Python HTTP server, SQLite, persistent pipeline runner. Preserve existing records, APIs, approvals and local authentication. Never fabricate traffic, leads, spending or delivery status. Distinguish completed builds from published websites. External integrations require real configured access.

## Core workflow
Idea → research → design/content → build and checks → review → launch → growth. Project artifacts and decisions supply persistent context. Users should see the next action and tangible output without knowing agent handles.
