# The Agency

A full AI agency in a folder: 13 specialists across 5 divisions, each with its own personality, skills, working method and definition of done. Write a profile once and use it everywhere: in Claude Code, in Cursor, as a plain system prompt, and (next) as the brief the Mission Control runner gives each agent.

## Quick start

Run from the repository root. On Windows use Git Bash.

```bash
bash agency/scripts/install.sh claude              # every agent, available in every project
bash agency/scripts/install.sh claude --project    # only this repository
bash agency/scripts/install.sh cursor              # .cursor/rules/*.mdc in this repository
bash agency/scripts/install.sh --list              # the roster with taglines
```

Then in Claude Code: *"use the backend-architect agent to design the invoices API"*. In Cursor: mention `@backend-architect` in chat, or let the agent pick the rule from its description.

More control:

```bash
bash agency/scripts/install.sh claude --division engineering      # one division
bash agency/scripts/install.sh cursor --agent deal-closer          # one agent (repeatable)
bash agency/scripts/install.sh claude --dry-run                    # preview changes
bash agency/scripts/install.sh claude --uninstall                  # remove only what it installed
bash agency/scripts/convert.sh prompt sales/deal-closer.md         # plain prompt to stdout
bash agency/scripts/convert.sh cursor design/*.md -o out/          # batch convert
bash agency/scripts/lint.sh                                        # validate every profile
```

Re-running `install` is safe: unchanged agents are skipped, edited ones are updated. Files you wrote yourself are never overwritten (unless `--force`) and never uninstalled; installed files carry a `generated by the-agency` marker.

## What each target gets

| Target | Location | Format |
|---|---|---|
| `claude` | `~/.claude/agents/<name>.md` or `./.claude/agents/` | Subagent: `name`, `description`, `tools`, then the profile as the system prompt |
| `cursor` | `./.cursor/rules/<name>.mdc` | Agent-requested rule: `description`, no globs, `alwaysApply: false` |
| `prompt` | stdout or `-o DIR` | No frontmatter. Paste into ChatGPT, Gemini, or an API system prompt |

The agency's own metadata (tagline, skills, voice) stays out of the converted files, so each assistant gets only the keys it understands.

## Profile format

Every profile is markdown with a flat frontmatter block. Copy [`_templates/agent-template.md`](_templates/agent-template.md) to start a new one.

| Key | Purpose |
|---|---|
| `name` | kebab-case, must match the filename |
| `title` | Display name |
| `division` | `engineering`, `design`, `marketing`, `sales` or `product`; must match the folder |
| `description` | What it does and when to use it. Assistants route on this, so name the jobs (60–320 chars) |
| `tagline` | One line in the agent's own voice |
| `skills` | `[list, of, skills]`, used for skill search |
| `works_with` | `[agent-names]` it hands work to and from; checked to exist |
| `tools` | Claude Code tool allowlist, e.g. `Read, Edit, Bash` |
| `voice_directness`, `voice_depth`, `voice_risk` | 1–10 personality dials: diplomatic→direct, lean→thorough, safe→bold |

Required body sections: **Mission, Personality, Use me for, How I work, Deliverables, Definition of done, Never, Handoffs**. `Not for` is recommended so each agent redirects work it shouldn't take.

## Rules every agent follows

1. **Outcomes over activity.** Each Definition of done is measurable.
2. **Evidence over invention.** No fabricated numbers, quotes, testimonials or sources.
3. **Humans own the irreversible.** Deploys, sends, publishes, signatures and money wait at an approval gate. The tests fail if an agent that can run commands or reach the public doesn't say so.
4. **Stay in lane.** Work that belongs to another specialist gets named and handed off.

## Adding a specialist

1. Copy the template into the right division folder and rename it to `<name>.md`.
2. Fill in every section. Make the description specific enough to route on.
3. Run `bash agency/scripts/lint.sh`, then `python -m unittest tests.test_agency_profiles`.
4. Run `install.sh` again.
